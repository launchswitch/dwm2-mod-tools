Useful Structures
-----------------

Boss battles (0x2881C) — 8 bytes per entry:
  0x0  2 bytes  Number of enemies -1
  0x2  2 bytes  First enemy (prebuilt ID)
  0x4  2 bytes  Second enemy (prebuilt ID)
  0x6  2 bytes  Third enemy (prebuilt ID)

Random encounter data (0x29773) — variable-length per area.
  Each area starts with a 2-byte LE pointer list, one per screen,
  pointing to the area's encounter structure(s). The structure is:
  0x0  1 byte   Maximum number of monsters per battle
  0x1  1 byte   Range (compared against 5 chance thresholds)
  0x2  5 bytes  Compare values 1-5 (cumulative chance bands)
  0x7  2 bytes  First enemy (prebuilt ID)
  0x9  2 bytes  Second enemy (prebuilt ID)
  0xb  2 bytes  Third enemy (prebuilt ID)
  0xd  2 bytes  Fourth enemy (prebuilt ID)
  0xf  2 bytes  Fifth enemy (prebuilt ID)
  Bytes 0x9-0x10 are only present if the corresponding enemy slot is used.
  Example (Oasis overworld): 01 07 03 07 00 00 00 02 00 03 00
  = max 1 enemy, range 7, 3/7 chance of prebuilt 0x02 alone, otherwise
  7/7 chance of prebuilt 0x03 alone.

Core monster data (0xd433b) — 47 bytes per species:
  0x0  1 byte   Family
  0x1  1 byte   Gender ratio (0 always male, 1 mostly male, 2 50/50, 3 mostly female)
  0x2  1 byte   Flying flag (LegSweep immunity)
  0x3  1 byte   Metal flag
  0x4  1 byte   Join rate (see JOIN_RATE enum)
  0x5  1 byte   Unknown (1=flying, 2=Water family, 3=Starfish)
  0x6  1 byte   Max level w/o breeding
  0x7  1 byte   Experience growth rate
  0x8  1 byte   Skill 1 ID
  0x9  1 byte   Skill 2 ID
  0xa  1 byte   Skill 3 ID
  0xb  1 byte   Unknown (related to random world selection?)
  0xc  1 byte   HP growth
  0xd  1 byte   MP growth
  0xe  1 byte   Atk growth
  0xf  1 byte   Def growth
  0x10 1 byte   Agi growth
  0x11 1 byte   Int growth
  0x12-0x2c 27 bytes  Resistances (one byte per element/effect ID; see RESISTANCE_ELEMENT_IDS)
  0x2d-0x2e 2 bytes  Base exp yield (LE u16)
